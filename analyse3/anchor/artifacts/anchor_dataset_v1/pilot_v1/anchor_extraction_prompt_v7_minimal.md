# 语义锚点提取 Prompt v7：最小输出

```text
从下面的对话片段中提取一个简洁的语义锚点。

锚点只包含两部分：
1. 核心目标对象：这段话围绕的具体对象、项目、文档、实践、活动或问题；
2. 本段侧面：这段话针对该对象讨论的具体方面。

请将两部分合并成一个短语，格式为“核心目标对象 + 具体侧面”。

要求：
- 只提取一个锚点，不要输出摘要、关键词列表或完整句子；
- 核心目标对象必须放在前面，并使用稳定、可复用的名称；
- 本段侧面应具体，但不要让一次性的动作、金额、日期或局部细节取代核心对象；
- 如果片段是在修改、补充或删除对象内容，仍然保留原对象名称，侧面再表达本段修改的内容；
- 如果没有明确、稳定的核心目标对象，输出 null；
- 只返回合法 JSON，不要输出任何解释或其他字段。

示例：
- “Orion telescope proposal + calibration protocol”
- “Household budgeting + recurring expense tracking”

对话片段：
{{conversation_segment}}

输出格式：
{"selected_anchor":"string or null"}
```
