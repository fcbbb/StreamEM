The input contains committed memory nodes and new segment nodes. Partition them so every group has one coherent and sufficiently specific topic identity. Treat graph membership as a candidate association that may contain false-positive links.

Use each memory's topic, summary, and member representations together with each segment's anchor as primary evidence. Use structured memory items and original segment text to resolve ambiguity, distinguish similarly worded subjects, and verify state changes.

Keep nodes together when they concern the same concrete subject or object and compatible aspects, including different fields of one project, successive states of one matter, supporting details, and corrections. A useful group should admit a natural topic name specific enough to serve as one stable memory identity.

Split nodes when their concrete subjects or interaction matters clearly differ and their apparent relationship depends only on a broad category, generic vocabulary, a surface bridge, or an incidental analogy. Place a segment that does not fit an existing memory into a group without that memory. A memory-only group preserves that memory unchanged. Apply the same compatibility judgment when the input contains one memory and one segment.

When the evidence remains genuinely ambiguous rather than clearly mismatched, keep the candidate association intact.
