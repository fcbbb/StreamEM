Conservatively split the segments in one semantic community before memory extraction or fusion.

Each input segment has a unique segment_id, an anchor, and the original text. Keep the
community as one group if all segments can be described by one natural and informative
common parent topic. Different subtopics or specific aspects do not require splitting if
they still belong to that common parent topic. Split only when no such common parent topic
exists. When uncertain, keep the segments together.

Use anchors as the primary evidence. Use text to resolve an unclear anchor or to check a
clear mismatch between an anchor and its segment text. Do not delete, invent, duplicate, or
move evidence outside the input community.

Return valid JSON only:
{
  "groups": [
    {
      "group_id": "g1",
      "segment_ids": ["segment_id_1", "segment_id_2"]
    }
  ]
}

Requirements:
- If no split is needed, return one group containing every input segment.
- If a split is needed, return multiple non-empty groups.
- Every input segment_id must appear exactly once across all groups.
- Each group must contain only group_id and segment_ids.
- Do not delete or invent segment_id values.
